# paperlight-support

The support page for [Paperlight](https://apps.apple.com/app/id6800686635), served by
GitHub Pages at **https://ardathepolatserve.github.io/paperlight-support/**

Apple requires a working support URL for every app, and it goes in the App Store Connect
listing. A support URL that 404s is a rejection.

## Editing

Plain HTML, no build step. `index.html` is the page, `style.css` carries Paperlight's own
colour tokens so it matches the app in light and dark. `.nojekyll` keeps GitHub from running
Jekyll over it.

The FAQ answers the questions a scanner app actually gets — where files live, why search
inside scans needs Pro, how to cancel, and what happens to documents when a subscription
ends. Keep that last one prominent: "your documents stay yours" is the top anxiety in this
category and the top one-star review when an app gets it wrong.
